# Recovery and attribution

This repository starts with a recovered academic project snapshot, imported on
2026-10-15. It does not reconstruct or backdate the original development history.

The source was recovered from the `SPL/Java/Assignment2/ass2` working directory.
Its contents matched the saved `assignment2.tar.gz` submission during the Desktop
inventory. The original directories and submission archive remain untouched.

The initial import contains all 48 recovered Java source/test files, the Maven
build, Makefile and the four input/configuration JSON files. Two comments exposing
a local Windows user-directory path were removed. Editor metadata, generated
outputs and the redundant submission archive were excluded.

This project was developed as coursework for System Programming Languages at
Ben-Gurion University. Existing framework/interface comments and example code
are retained. The exact boundary between supplied starter code, individual work
and any teammate contributions has not been established from this snapshot.
The repository should remain private until attribution and course publication
conditions have been confirmed. No open-source license is asserted here.

Subsequent commits record actual preparation, fixes, tests and documentation
performed after recovery. They are not presented as the original project timeline.
